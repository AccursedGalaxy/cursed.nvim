INTRODUCTION                                              *cursed* *cursed.nvim*

cursed.nvim sends your buffer's LSP diagnostics to Claude Code running in a
tmux pane. One command pastes all current errors and warnings directly into
your Claude Code session so you can ask for fixes without copy-pasting.

Features:
- Send diagnostics from the current buffer, all buffers, or the whole
  workspace
- Severity filtering, format control (default / compact / with source lines)
- Prompt templates to wrap diagnostics before sending ("fix", "explain", ...)
- Preview and edit the message in a floating window before sending
- Auto-send on DiagnosticChanged with configurable debounce
- User autocmd events (CursedPreSend, CursedPostSend, CursedSendFailed)
- Statusline / lualine component showing last send time
- Telescope picker for interactive multi-diagnostic selection

==============================================================================
REQUIREMENTS                                              *cursed-requirements*

- Neovim >= 0.11.0
- tmux (with at least one active session)
- Claude Code running inside a tmux pane

==============================================================================
INSTALLATION                                              *cursed-installation*

lazy.nvim: >lua
  {
    "AccursedGalaxy/cursed.nvim",
    config = function()
      require("cursed").setup({
        tmux = { pane_target = "{left}", auto_submit = true },
      })
    end,
  }
<

rocks.nvim (rocks.toml): >toml
  [plugins]
  "cursed.nvim" = "scm"
<

CONFIGURATION                                             *cursed-configuration*

Pass a table to |cursed.setup()|. All keys are optional; unset keys use the
defaults shown below.

>lua
  require("cursed").setup({
    -- ── Transport ────────────────────────────────────────────────────────
    backend          = "tmux",       -- string: "tmux" (only option for now)
    tmux = {
      pane_target    = "{left}",     -- string: tmux target-pane syntax
      auto_submit    = true,         -- true  → paste + Enter (Claude starts immediately)
                                     -- false → paste only; edit in pane, press Enter yourself
      paste_delay_ms = 300,          -- ms between paste and Enter; increase on slow machines
    },

    -- ── What to collect ──────────────────────────────────────────────────
    scope            = "buffer",     -- "buffer" | "all_buffers" | "workspace"
    min_severity     = vim.diagnostic.severity.HINT,  -- HINT=4 INFO=3 WARN=2 ERROR=1

    -- ── How to format ────────────────────────────────────────────────────
    format           = "default",    -- "default" | "compact" |
                                     -- "with_source_lines" | function(d, bufnr)

    -- ── Prompt templates ─────────────────────────────────────────────────
    -- Use {content} as the placeholder ({diagnostics} is a legacy alias).
    -- Pass the key as arg to :CursedSendDiags or :CursedSendSelection,
    -- e.g. :CursedSendDiags explain  or  :CursedSendSelection fix_selection
    templates = {
      -- diagnostics templates
      fix     = "Please fix these diagnostics:\n\n{diagnostics}",
      explain = "Explain these diagnostics:\n\n{diagnostics}",
      test    = "Write tests that cover these diagnostics:\n\n{diagnostics}",
      -- selection templates
      fix_selection     = "Please fix the following code:\n\n{content}",
      explain_selection = "Explain the following code:\n\n{content}",
      review            = "Review the following code and suggest improvements:\n\n{content}",
    },
    default_template = nil,          -- string | nil: applied automatically on every send

    -- ── Auto-send on DiagnosticChanged ────────────────────────────────────
    auto_send = {
      enabled        = false,        -- boolean
      event          = "DiagnosticChanged",  -- string: autocmd event
      debounce_ms    = 500,          -- number: ms to wait after last event
      min_severity   = vim.diagnostic.severity.ERROR,
      scope          = "buffer",
    },

    -- ── Keymaps ───────────────────────────────────────────────────────────
    -- Set any value to false to disable, or a string to remap.
    -- Unknown key names produce a warning.
    keymaps = {
      send              = nil,       -- string | nil: normal-mode, e.g. "<leader>cd"
      send_selection    = nil,       -- string | nil: visual-mode, e.g. "<leader>cs"
      preview_send      = "<CR>",    -- confirm & send inside preview window
      preview_close     = "q",       -- close preview without sending
      preview_close_esc = "<Esc>",   -- close preview without sending (Esc)
    },

    -- ── Pre-send command ──────────────────────────────────────────────────
    -- Sends a command to the pane before pasting diagnostics.
    -- command = nil disables the feature entirely.
    -- Per-feature: nil = follow global, false = suppress for that feature.
    pre_send = {
      command   = nil,     -- string | nil: e.g. "/clear"; nil = feature off
      delay_ms  = 300,     -- number: ms to wait after command before pasting
      send      = nil,     -- nil: follows global  (manual send / keymap)
      auto_send = nil,     -- nil: follows global  (consider false to reduce noise)
      preview   = nil,     -- nil: follows global  (:CursedPreview send action)
      pick      = nil,     -- nil: follows global  (:CursedPick send action)
      selection = nil,     -- nil: follows global  (:CursedSendSelection / visual keymap)
    },
  })
<

Options ~

`backend` (string, default: `"tmux"`)
  Transport backend. Currently only `"tmux"` is supported.

`tmux.pane_target` (string, default: `"{left}"`)
  tmux pane address. Accepts any valid tmux target-pane syntax:
  - `"{left}"` — pane to the left of the current one
  - `"myclaude"` — named session
  - `"%3"` — pane by ID
  - `"mysession:1.0"` — session:window.pane

`tmux.auto_submit` (boolean, default: `true`)
  Paste the text then send Enter after a short delay so Claude starts
  processing. The Enter is sent asynchronously after `paste_delay_ms` to
  avoid racing with Claude Code's input handler.

`tmux.paste_delay_ms` (number, default: `300`)
  Milliseconds between the paste and the Enter keypress when `auto_submit`
  is `true`. Increase this on slow machines or when sending large payloads.

`scope` (string, default: `"buffer"`)
  Which diagnostics to collect:
  - `"buffer"` — current buffer only
  - `"all_buffers"` — all loaded buffers
  - `"workspace"` — all buffers with an active LSP client

`min_severity` (number, default: `vim.diagnostic.severity.HINT`)
  Minimum severity to include. Lower numbers = more severe:
    ERROR=1, WARN=2, INFO=3, HINT=4
  Use `vim.diagnostic.severity.ERROR` to send errors only.

`format` (string|function, default: `"default"`)
  Output format:
  - `"default"` — `[ERROR] 12:5  message (source)`
  - `"compact"` — `file.lua:12:5: ERROR: message`
  - `"with_source_lines"` — like default, plus the erroneous source line
  - function — `fn(diag, bufnr) -> string|nil` called per diagnostic;
    returning `nil` omits that diagnostic from the output

`templates` (table)
  Named templates for wrapping content before sending. Use `{content}` as the
  placeholder; `{diagnostics}` is accepted as a legacy alias. Any key name is
  valid; pass it as an argument to |:CursedSendDiags| or
  |:CursedSendSelection|.

`default_template` (string|nil, default: `nil`)
  Template to apply automatically on every send. `nil` means no wrapping.

`auto_send.enabled` (boolean, default: `false`)
  Enable automatic sending when diagnostics change.

`auto_send.debounce_ms` (number, default: `500`)
  Wait this many milliseconds after the last event before sending. Prevents
  flooding when diagnostics update rapidly during typing.

`auto_send.min_severity` (number, default: `vim.diagnostic.severity.ERROR`)
  Auto-send only triggers for diagnostics at or above this severity.

`keymaps` (table)
  All user-facing keymaps. Set any value to `false` to disable it, or a
  string to remap it. Unset keys use the defaults shown in the config block.

  `keymaps.send` (string|nil, default: `nil`)
    Global normal-mode keymap bound to `send_diagnostics()`. Equivalent to
    a no-argument |:CursedSendDiags|. Example: `"<leader>cd"`.

  `keymaps.send_selection` (string|nil, default: `nil`)
    Visual-mode keymap bound to |:CursedSendSelection|. Example:
    `"<leader>cs"`. When triggered from visual mode the current selection is
    used; you are then prompted for an instruction to prepend.

  `keymaps.preview_send` (string|false, default: `"<CR>"`)
    Inside |:CursedPreview|: send the (possibly edited) content and close.

  `keymaps.preview_close` (string|false, default: `"q"`)
    Inside |:CursedPreview|: close without sending.

  `keymaps.preview_close_esc` (string|false, default: `"<Esc>"`)
    Inside |:CursedPreview|: close without sending (Esc variant).

  Note: passing an unknown keymap key emits a `WARN` notification.

`pre_send` (table)
  Send a command to the tmux pane *before* pasting diagnostics. Useful for
  running `/clear` to reset Claude Code's context between sends.

  `pre_send.command` (string|nil, default: `nil`)
    The command string to send. `nil` disables the feature entirely.
    Example: `"/clear"`

  `pre_send.delay_ms` (number, default: `300`)
    Milliseconds to wait after sending the command and before pasting the
    diagnostics. Gives Claude Code time to process the command.

  Per-feature keys: `pre_send.send`, `pre_send.auto_send`, `pre_send.preview`,
  `pre_send.pick`, `pre_send.selection` (false|nil, default: `nil`)
    Set to `false` to suppress the pre-send command for that specific feature.
    `nil` means the feature follows the global `pre_send.command` setting.
    Example: set `auto_send = false` to skip `/clear` on automatic sends.

==============================================================================
COMMANDS                                                      *cursed-commands*

:Cursed                                                             *:Cursed*
  Display a notification confirming the plugin is loaded. Useful for
  verifying your install.

:CursedSendDiags [{arg}]                                    *:CursedSendDiags*
  Collect and send diagnostics to the configured Claude Code pane.

  Optional {arg} is either:
  - A scope: `buffer`, `all_buffers`, `workspace` — overrides `config.scope`
    for this send only.
  - A template name: `fix`, `explain`, or any key in `config.templates` —
    wraps the diagnostics block in the template before sending. An unrecognised
    template name is silently ignored and the text is sent unwrapped.

  Examples: >
    :CursedSendDiags
    :CursedSendDiags workspace
    :CursedSendDiags explain
<

:CursedSendSelection [{template}]                      *:CursedSendSelection*
  Send the current visual selection to the configured Claude Code pane.

  When called without an argument, opens `vim.ui.input` so you can type an
  instruction; the instruction is prepended before the file context and code.

  When called with a template name, applies that template immediately without
  prompting. The selected code is substituted into the `{content}` placeholder.

  The command accepts a range; it is typically invoked as `'<,'>CursedSendSelection`.

  Examples: >
    :'<,'>CursedSendSelection
    :'<,'>CursedSendSelection fix_selection
    :'<,'>CursedSendSelection review
<
  Or via the `send_selection` keymap (visual mode): >lua
    keymaps = { send_selection = "<leader>cs" }
<

:CursedPreview                                              *:CursedPreview*
  Open a floating window containing the formatted diagnostic text. You can
  edit the text freely before sending. See |cursed-keymaps| for controls.

:CursedPick                                                   *:CursedPick*
  (Requires telescope.nvim) Opens a Telescope picker listing all diagnostics
  from all loaded buffers (ignores `config.scope`). Select one to send it.
  Only registered when telescope.nvim is detected at startup.

:CursedSendCommand {text}                              *:CursedSendCommand*
  Send an arbitrary string to the configured Claude Code tmux pane. Respects
  `tmux.pane_target` and `tmux.auto_submit` from config.

  Examples: >
    :CursedSendCommand /clear
    :CursedSendCommand /help
<
  From Lua (e.g. in a keymap): >lua
    require("cursed").send_command("/clear")
<
  With opts: >lua
    require("cursed").send_command("/clear", { auto_submit = true })
    require("cursed").send_command("/clear", { pane_target = "%3" })
<

==============================================================================
KEYMAPS                                                       *cursed-keymaps*

Inside the |:CursedPreview| floating window: ~

  Default keymaps (all overridable via `config.keymaps`):

  `keymaps.preview_send`      (default <CR>)   Send content and close.
  `keymaps.preview_close`     (default q)      Close without sending.
  `keymaps.preview_close_esc` (default <Esc>)  Close without sending.

  Set any of these to `false` to disable, or a string to remap. The preview
  window title reflects the currently configured send and close keys.

EVENTS                                                         *cursed-events*

cursed.nvim fires |User| autocmds you can hook into from other plugins or
your own config. All events pass a `data` table.

  `CursedPreSend`     Fired before sending. data: `{ text, backend }`
  `CursedPostSend`    Fired after a successful send. data: `{ text, backend }`
  `CursedSendFailed`  Fired after a failed send. data: `{ text, backend }`

Example: >lua
  vim.api.nvim_create_autocmd("User", {
    pattern = "CursedPostSend",
    callback = function(ev)
      vim.notify(string.format("cursed: sent %d chars", #ev.data.text))
    end,
  })
<

STATUSLINE                                                 *cursed-statusline*

`lua/cursed/statusline.lua` exposes a component showing send status.

`require("cursed.statusline").component()` → `string`
  Returns one of:
  - `"cursed: sending…"` — a send is in progress
  - `"cursed: sent Xs ago"` — last send succeeded
  - `"cursed: failed Xs ago"` — last send failed
  - `""` — nothing has been sent yet

`require("cursed.statusline").lualine` → `table`
  A ready-made lualine component table with a `cond` that hides it when
  nothing has been sent.

lualine integration: >lua
  require("lualine").setup({
    sections = {
      lualine_x = { require("cursed.statusline").lualine },
    },
  })
<

Manual statusline integration: >lua
  vim.o.statusline = "%{%v:lua.require('cursed.statusline').component()%}"
<

HEALTH CHECK                                                   *cursed-health*

Run `:checkhealth cursed` to verify:

  ✓ Neovim >= 0.11.0
  ✓ plugin loaded (vim.g.loaded_cursed)
  ✓ setup() has been called
  ✓ tmux is installed (found in PATH)
  ✓ tmux server is running (tmux list-sessions exits 0)
  ✓ LSP clients active (info only — plugin works without LSP loaded)
